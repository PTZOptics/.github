# Welcome to the PTZOptics GitHub 👋

Welcome to the official GitHub home for PTZOptics! We provide open-source tools, software plugins, and code examples to help developers, broadcasters, and AV professionals seamlessly integrate and control their PTZ cameras.

## 🚀 Featured Repositories

Whether you are automating a broadcast or integrating cameras into a larger AV ecosystem, these repositories will get you started:

* **[Code Examples](https://github.com/PTZOptics/Code-Examples)**  
  Sample code, scripts, and snippets demonstrating how to interface with PTZOptics cameras across various programming languages.
* **[Q-Sys Plugin](https://github.com/PTZOptics/PTZOptics-Q-Sys-Plugin)**  
  The official plugin for seamlessly integrating PTZOptics cameras into your Q-SYS audio, video, and control ecosystem.
* **[OBS Plugin](https://github.com/PTZOptics/OBSPlugin)**  
  Our dedicated plugin for OBS Studio, allowing for direct camera control (Pan, Tilt, Zoom, and Presets) right from your broadcasting environment.
